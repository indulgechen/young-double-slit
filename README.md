## 课件里有什么

- **3D 光路**：L → S → S₁、S₂ → P，可拖拽旋转、滚轮缩放
- **三个滑杆**：波长 λ（400–700 nm）、缝距 d（0.06–0.50 mm）、缝屏距 d′（0.5–2.0 m）
- **光程差面板**：实时给出 `Δr = 0.55 µm = 1.00 λ = 2.00 × λ/2`，配半波长刻度尺 —— **m 偶 → 明纹，m 奇 → 暗纹**
- **可拖动的观察点 B**：在光强曲线上拖动，3D 里同步画出 `r₁`、`r₂` 两条光路
- **白光模式**：中央白色、两侧彩色，条纹迅速模糊
- **四步讲解**（入射 → 分波 → 叠加 → 条纹）+ 四个知识卡片 + 入场构建动画
- **手机 / 平板 / 电脑全适配**：竖屏是「标题 + 3D + 步骤 + 底部参数面板」，横屏自动切换成右侧参数列，触屏支持拖动旋转、双指缩放

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 旋转光路 | 拖拽 | 单指拖动 |
| 缩放 | 滚轮 | 双指捏合 |
| 移动观察点 B | 在光强曲线上拖动 | 拖「观察点 x」滑杆 |
| 切换步骤 | `1`–`4` 或点按 | 点按 |
| 暂停 / 重播 / 全屏 | `空格` / `R` / `F` | 右上角按钮 |
| 知识卡片 | 点 ①–④ | 点 ①–④（底部弹出） |

## 想改成自己的课

`index.html` 里的代码是分块注释过的，用 VS Code 打开搜索这些关键字即可：

| 想改什么 | 搜索 | 说明 |
| --- | --- | --- |
| 四个知识卡片的文字与公式 | `const SPOTS` | `anchor` 是三维锚点，`dx/dy` 是标签偏移 |
| 四个步骤的文案 | `const STEPS` | `fx.beam / wave / glow` 控制强调程度 |
| 默认参数 | `const P = {` | λ、d、d′、观察点位置、是否白光 |
| 刻度尺范围 | `OD_MAX` | 默认半波长刻度到 m = 12 |
| 屏显示范围 | `SCREEN_MM` | 默认 30 mm（±15 mm） |
| 配色 | `PALETTE` 与 CSS 变量 | 纸张色、朱砂色、器件灰 |

### URL 参数

- `?still` 跳过入场，直接定格
- `?still&white=1` 白光
- `?still&lam=650&d=0.4&D=1.4` 预设参数（`D` 即 d′）
- `?still&x=2.75` 把观察点 B 放在指定位置（mm）
- `?still&spot=screen` 直接打开某个热点（`laser / slits / overlap / screen`）

## 一点说明：示意图与真实数据

教材里 `d ≈ 0.2 mm`、`d′ ≈ 1–10 m`，两者相差 10⁴ 量级，无法和米级光具座画在同一张图里。因此 **3D 场景中的缝距、偏角、波前间距都做了放大**（图注已注明）；但**屏上 ±15 mm 内的条纹数与右栏曲线严格按公式计算**，拖动参数会真的变化。
